# Landing page — Ministério Mintre

Landing page estática e responsiva do Ministério Mintre.

## Estrutura

```text
index.html          # Estrutura e conteúdo da página
assets/
  css/styles.css    # Estilos e responsividade
  js/script.js      # Menu, animações e acordeão da agenda
  images/           # Fotos, logos e demais imagens
```

## Visualizar

Na pasta do projeto, execute:

```bash
python3 -m http.server 4173
```

Depois, acesse `http://localhost:4173`.

## Conteúdo usado

- Missão: Resgatar, Restaurar e Ensinar.
- Lema: Opção de liberdade.
- Liderança: Pastor Joilson e Pastora Leia.
- Endereço: Av. Dr. Timóteo Penteado, 1059 — Guarulhos/SP.
- Horários: terça às 20h; Escola Bíblica domingo às 17h45; celebração domingo às 19h.

As imagens atuais foram obtidas de capturas do Instagram. Para uma publicação definitiva, recomenda-se substituí-las pelas fotografias originais e por um arquivo vetorial oficial do logotipo.
